# Orbit

Orbit is an innovative online safety helper for parents. It’s aimed toward parents of children aged 8-15. Screenshots of a child’s screen will be analyzed for negative impact/danger to the child and reported if such is present and viewed via this parent dashboard.

# Stack

This project is powered by React + TypeScript + Vite.

# Tasks

1. Use the interface to view recent incidents that occurred and learn details about them.
2. Filter and review only high-risk events that occurred within the past 24 hours.
3. Learn about the websites/apps your child is using so you can make decisions on whether they are safe for your child.
